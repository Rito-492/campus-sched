交付：列表、分步申请表、详情、审批/资源待办、发布/取消/报名，最新lockVersion；API-12～23。

验收：先保存草稿得ID再预览；资格提示到具体场地/设备；冻结/满额/旧版/超时有反馈；同key重试且保留表单。
