作者：杨畅（17231018）。日期：2026-10-31。基准main=feb0d70；分支work/17231018-ui；本地追加实现，尚未发布。保留原`interface-description.md`设计文档与课程Word，本文件单独说明本版本实际界面。

| 路由 | 本版实际界面与行为 |
|---|---|
| /login | 账号密码、真实登录、错误追踪编号；会话恢复/过期跳转 |
| /activities | 我的/公开范围、状态筛选、资源风险、参与人数、活动与改期入口 |
| /activities/new | 四步申请、资格说明、人员选择、保存真实草稿后进入详情 |
| /activities/:id | 当前安排、草稿编辑、资源检查/候选、审批/预约/发布/报名/撤回/取消；人员、名单、改期、审计页签 |
| /resources/calendar | 日期/资源查询、半小时刻度、布场/活动/撤场/故障、设备同时用量/故障扣减、明细抽屉；手机列表 |
| /resources/manage | 按范围只读/可管理、新增场地设备、两项资格开关、故障登记及受影响活动 |
| /activities/:id/change | 目标表单、冲突、最多5候选/2～3项比较、最终目标重预览、四组影响、原因/创建 |
| /changes/:id | 原新快照及当前有效安排、人员/复审/资源时间线、本人操作、撤回/拒绝原因、实时风险/冲突、生效后刷新 |
| /reviews | 首次审批/预约待办与待处理改期；关联查询最多6并发、部分失败和截断提示 |
| /notifications | 未读筛选、活动版本与跳转、标为已读；不代替人员确认 |
| /admin/users | 列表/新建/启停/完整授权编辑，身份独立于角色，完整替换确认及本人失权处理 |

全局沿用common/05视觉变量，224px导航/64px头部；1024px以下折叠导航，768px以下日历使用列表、改期差异堆叠。时刻统一北京时间，三视口为1366×768、1920×1080、390×844。长资源名可换行，时间块提供明细/标题；半小时刻度分两行排列避免相邻标签挤压。

错误状态保留服务端code/details/requestId；返回列表截断时不宣称完整或空闲。持久操作结果未知时锁定新提交并保留原幂等请求，已确认写入后的刷新失败不重写。草稿版本冲突保留输入，最终改期预览绑定目标与版本，变化即失效。权限来自Actor明确授权，不推导教师审批、管理员全权或自审。

开发预览复用上述组件但不代表真实服务可用，样例数据/状态在页面显著标注。生产构建不包含预览入口或fixture。2026-10-31新增真实认证/账号/资源/草稿局部联调与后端重启复验，15张真实页面截图见`artifacts/screenshots/ui-integration-2026-10-31/`；完整预约/报名/改期、QA E2E及交叉视觉验收仍受后端缺口阻塞。

资格失败直接展示受限资源名及追踪编号；拒绝改期采用理由必填弹窗，状态/权限失效不能提交。新增扩展testid及真实操作路径见`real-integration-2026-10-31.md`，未改共享DTO。

真实命令与结果见`handoff.md`；API逐项接入与稳定测试标识见`api-matrix.md`；用户操作说明见`user-manual.md`。PR草案在`pr-draft.md`，未经用户确认不提交。
