# UI-01 核心交互原型 v0.1

运行 `web` 的 `npm run dev`，打开 `http://127.0.0.1:5173/__prototype`。

实际实现位于 `web/src/dev/PrototypePage.vue`，复用 `web/src/components/` 中的资源日历、冲突列表、候选对比、安排影响和确认时间线。覆盖 common/05 的四个核心交互：

1. 资源日历：资源行/时间轴/布场条目/明细抽屉，手机转列表。
2. 冲突与备选：精确区间、缺口，最多5项、2～3项比较；选择只发出组件事件，不预约。
3. 差异与影响：原新安排并列、资源/审批/工作人员/报名通知四组影响，实时风险独立于快照。
4. 确认与结果：人员、复审、资源时间线，待处理及失败/生效结果的表现。

当前为组件交互原型，不是生产业务闭环。原型数据使用2030-10-20虚构安排，固定展示“演示数据 / 未连接后端”，不创建会话、不请求后端。正式build剔除全部开发入口和fixture。

三视口截图及执行说明以 `docs/ui/handoff.md` 为准；不得把原型截图描述为真实预约/改期成功。

2026-10-31追加工作台外观：`/__prototype/workspace`复用正式布局，支持教师申请人、学生申请人、批准人、资源管理员、账号管理员五个示例视角。资源管理员可进入资源管理查看资格和故障表单，写入禁用；资源日历增加同时设备用量/故障样例。活动详情提供改期工作台及进度外观入口，候选可切换0/5项，进度可切换待处理/冲突/生效等固定样例。所有切换只影响组件展示，仍不发送API、不产生会话。
