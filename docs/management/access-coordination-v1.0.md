日期：2026-10-31；组织人：冀项阳55230223（PM-04）。依据：common/01的最小披露、common/02 API-13/14/23、common/05的待办发现方式，以及AN已登记的B/D/I建议。本文件区分当前代码与待接收方案，不代替AN/DS/QA签字，不修改其源码。

## 1 当前实现的访问矩阵

所有入口先验证会话、启用状态和最新账号；下表中的“范围”包含组织及全部必要资源类别，资源确认还必须具备ADMIN、RESOURCE_CONFIRM及全部资源范围。本人申请不得审批或资源复核。

| 入口与关系 | 当前可读范围 | 字段与限制 |
|---|---|---|
| API-13 public；任意已登录启用账号 | OPEN | 非特权视图隐藏工作人员ID |
| API-13 mine；当前具有APPLICANT | 本人所有、当前工作人员、任意报名历史的并集；可再按状态过滤 | 三分支去重，不能只查所有者；撤销APPLICANT后列表403 |
| API-13 review；非所有者的范围内批准人或资源复核管理员 | PENDING_APPROVER、APPROVED_UNRESERVED、SCHEDULED、OPEN | DRAFT、CANCELLED不进入此列表；角色和范围在SQL中先过滤 |
| API-14；所有者 | 六种活动状态 | 当前实现不要求读取时仍具APPLICANT；写操作另行校验 |
| API-14；当前工作人员或本人任意报名历史 | 六种状态，包括退出/取消后的本人历史 | 隐藏工作人员ID；不因此获得API-23名单权限 |
| API-14；范围内批准人或资源复核管理员 | 当前实现未按状态收紧，包含DRAFT/CANCELLED | 这是待协调的D项，不能把现状当作已获隐私评审放行 |
| API-23；所有者或范围内批准人/资源复核管理员 | 当前实现授权后可读名单 | 工作人员或普通报名者的关系本身不足以授权 |
| 无上述关系的账号 | OPEN公开详情；其他状态403 | 仅教师身份、USER_MANAGE或相同组织不产生访问权 |

列表均按权限过滤后取201项，仅返回200项并保留truncated；公开简介不承载审批意见。已预约视图可能因真实ChangePort缺失返回503，不能将这种依赖错误解释为已验证访问成功。

## 2 B项的基线解释与UI接收条件

review是待办的**候选发现集合**。common/05明确先取review活动，再读取其改期；SCHEDULED/OPEN仍可能有待处理改期。因此本轮保留现有四状态集合，不把review直接缩成两种首次审批状态，也不将集合长度显示为“待我处理总数”。UI应依据实际活动/改期状态及当前职责筛选可执行卡片，变更最终仍由后端校验。

AN/QA需核对：DRAFT/CANCELLED不进入review；所有者回避；批准组织/类别或资源范围不足不进入集合；SCHEDULED/OPEN能发现待改期；显式status参数不能扩大授权范围；截断和缺CM时提示真实失败。UI候选已存在，不再登记为工程未交付；该解释的接收确认仍待AN/UI/QA评审。

## 3 D项的具体评审提案

提案将“审批发现、历史读取、业务操作”分开：

1. 不因批准/复核角色而允许读取他人未提交DRAFT；所有者、当前工作人员及本人报名历史的既有关系规则保留。
2. CANCELLED允许当前范围内批准人/资源复核管理员读取必要历史，但不能执行审批、复核、发布、报名等状态转换；读取与名单字段分别校验，不恢复旧权限。
3. 公开/关系视图继续裁剪工作人员，名单不因关系自动开放。会话停用或范围撤销立即生效。

这是供AN/QA确认的最小规则提案，**尚未写入公共契约或部署实施**。AN需给出API-14/23及日历一致性测试，QA补正负边界，PM在确认后统一更新common/02/OpenAPI；不能仅凭本文件将D项关闭。

## 4 I项的最小接口提案

AN当前直接消费DS的ResourceRepository读取类别并锁资源。预约写入已经经SchedulingPort；本轮不接管AN/DS实现。建议保持五类端口，不新增第六类端口或HTTP接口：

```java
// 仅供评审，尚未加入接口；DS实现类别读取，不进行业务写入。
Set<String> resourceCategories(Plan plan);
```

由SchedulingPort增加上述只读能力后，AN用其完成类别授权；提交需要的资源锁复用既有lockAndCheck，提交阶段仍不写预约、不因容量冲突提前占位。DS需确认该调用对检查凭据、锁序及事务的语义；AN按确认后的调用点替换Repository依赖。

影响：API-16/18及权限视图内部编排、SchedulingPort、AN/DS模块测试；无新DTO、表或公共字段。必须由DS交实现与测试、AN交替换及无循环证明、QA复验，再由PM同步共享签名。当前未添加抽象方法破坏已有构建，也未用默认空实现掩盖缺口。
