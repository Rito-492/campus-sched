# 仓库结构与目录指南

| 目录 | 内容 |
|---|---|
| `agents/common/` | 开发、接口、验收、协作和界面基线 |
| `agents/<岗位>/` | 按岗位维护的开发工作包，入口见[岗位开发说明](../../agents/README.md) |
| `docs/requirements/` | 需求、用例、业务规则、补充规约、需求追踪 |
| `docs/design/` | 系统设计、数据库设计和迁移登记 |
| `docs/ui/` | 界面说明和用户手册 |
| `docs/testing/` | 测试设计、报告、覆盖矩阵、数据规则和评审清单 |
| `docs/management/` | 公共模块接入说明 |
| `docs/configuration/` | 目录指南 |
| `server/` 与 `web/` | Java 后端与 Vue 前端 |
| `qa/` 与 `test-data/` | 端到端测试、检查脚本和演示数据 |
| `contracts/` | OpenAPI 契约 |
| `infra/` 与 `scripts/` | 数据库初始化、反向代理和环境检查脚本 |
| `release/` | 演示启动、备份和恢复说明 |
| `artifacts/` | 经过核对的测试摘要、手册截图、策略评测 |
| `models/` | Drawio 图源和同名导出图 |

## 归档

课程原件、总任务书、课程导出配置和原始日志在维护者本地保留。公开文档及验收证据的跟踪范围由根目录 `.gitignore` 的清单管理。新增材料时先检查正文、文件名、元数据、图片以及引用路径，再通过仓库评审更新清单。

接口字段和状态机遵循开发基线 v3.0。模型变更同步设计文档，构建和验证按各模块入口执行。课程原件与冻结基线按配置变更规程保管。
